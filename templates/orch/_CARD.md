# T번호 역할 - 카드 이름

이 파일은 카드 양식이다. 메인이 복사해 `orch/T03-build-login.md`처럼 만든다.

## 지시 (메인이 쓴다)
- 목표 (업무 말 한 줄):
- 관련 요구 ID:
- 담당 파일 (이 파일들만 고친다):
- 통합 뒤 담당이 바뀌는 파일 (예: T01의 공통 파일 → 메인):
- 읽을 것 (계약 항목, 다른 카드, 문서 위치):
- 완료 기준 (실행해서 확인할 명령과 기대 결과):
- 가장 위험한 실패 (사용자 확인):
- 하지 않을 것:
- 먼저 끝나야 하는 카드:

## 결과 (맡은 세션이 쓴다. 차수 작성·갱신은 AGENTS.md의 소통 파일 규칙을 따른다)

### 1차 - 터미널 번호, 시작 시각
- 상태: 진행 / 완료 / 막힘 / 사용자 실행 대기 / 인계
- 한 것:
- 근거 (실행 명령과 결과):
- 계약과 달라진 점:
- 다른 역할에 넘길 것:
- 사용자가 정할 것 (질문, 선택지, 추천과 이유, 다른 카드 영향 가능성):
- 사용자가 정한 것 (결정, 시각, 다른 카드 영향 있음/없음):
- 막힘 (막혔을 때만): 오류 메시지 / 재현 명령 / 시도한 것 / 의심 가는 곳
