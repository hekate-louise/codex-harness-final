# 요구사항 (메인만 고친다)

과제 지정 문서가 같은 역할이면 그 파일을 쓴다. 필수 항목을 임의로 줄이지 않는다. 인터뷰 답은 docs/INTERVIEW.md에서 옮겨 온다.

## 문제와 사용 환경
- 누가 / 어떤 업무 / 현재 불편:
- 성공하면 달라지는 것:
- 사용자 역할(예: 운영자, 일반 사용자):
- 실제 실행 환경(설치·인터넷·브라우저·배포·도커):
- 입력 형식·규모 / 출력·사용처:
- 데이터·보안 제약:

## 문제 정리 (최적화가 있으면)
사용자가 정한다. 모르면 질문으로 남긴다.
- 결정할 것(무엇을 고르나):
- 반드시 지킬 조건(Hard):
- 가능하면 줄이거나 늘릴 값(Soft, 목표):
- 목표가 여럿이면 우선순위:
- 계산 시간 한도:
- 결과 상태: 최적 / 실행 가능하지만 최적 보장 없음 / 해 없음 / 시간 초과
- 최적 보장 여부:
- 동률 처리 기준:
- 입력 규모와 계산 방법(전수, 탐욕, 정수계획 등)과 그 이유: DECISIONS.md 참조
