# 데이터 흐름 표 (문서 역할만 고친다)

데이터마다 어디서 생기고, 원본이 어디 있고, 누가 읽고, 누가 고칠 수 있는지 적는다. 코드에서 확인한 사실만 쓰고 파일·함수 이름을 붙인다.

## 데이터별 표
| 데이터 | 만드는 곳 (화면·기능) | 원본 위치 (Source of Truth) | 읽는 곳 | 수정 권한 (역할·본인만) | 권한 확인 위치 (서버 함수) | 파생값이면 계산 위치 |
|---|---|---|---|---|---|---|

## 흐름 예시
요청 하나가 화면에서 저장소까지 가는 길을 한 줄씩 적는다.
- 예: `요청 화면 → POST /requests(서버, 로그인·역할 확인) → requests 표`

## 브라우저에만 있는 값
저장 전 입력, 화면 필터처럼 서버로 가지 않는 값과, 서버 값과 다를 때 무엇이 기준인지.

## 용어
- Source of Truth: 여러 곳에 같은 값이 있을 때 진짜 원본
- 파생 데이터: 원본에서 계산한 값. 저장하면 원본과 어긋날 수 있다
- 인증 / 인가: 누구인지 확인 / 무엇을 할 수 있는지 확인
