# 발표 원고 (문서 역할만 고친다)

약 2분 분량. 사용자가 직접 소리 내어 읽어 보고 자기 말로 고친다. 기록에 없는 성과를 쓰지 않는다.

## 원고
1. 문제 (15초): 누가 어떤 일에서 무엇이 어려웠나
2. 해결 (30초): 무엇을 만들었고 역할별로 무엇을 할 수 있나
3. 핵심 판단 (30초): 가장 중요한 선택 1~2개와 이유 (DECISIONS.md)
4. 근거 (30초): 결과가 맞다는 것을 어떻게 확인했나 (VERIFY.md)
5. 한계와 다음 (15초)
