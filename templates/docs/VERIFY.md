# 검증 기록 (검증 역할만 고친다)

구현과 별개인 기준으로 확인한 결과다. 구현 세션의 자체 확인은 각 카드 결과에 있다.

## 위험 기준
사용자가 말한 "가장 피해가 큰 실패"를 적는다. 말하지 않았으면 검증 전에 묻는다.
-

## 검증 항목
| ID | 요구 ID | 무엇을 | 명령 또는 수동 동작 | 기대값·출처 | 실제 결과 | 판정 |
|---|---|---|---|---|---|---|

판정: 통과 / 실패 / 미검증. 사용자의 화면 확인은 사용자가 답하기 전까지 미검증이다.

## 독립 검산
- 계산 결과: 작은 입력을 전수 계산하거나 손으로 계산한 값과 비교
- 권한: 다른 역할·다른 사용자로 직접 주소를 요청해 막히는지
- 저장: 서버를 다시 띄운 뒤 데이터가 남는지
