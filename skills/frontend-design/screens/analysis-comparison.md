# 분석·비교·검토 화면 유형

공통 색과 시각 원칙은 [디자인 기준](../design-reference.md)을 따른다.

## 사용할 때

기간별 성과, 여러 후보 또는 조건을 비교하고 근거를 확인하는 업무. 시장 분석, 후보 평가, 계획 결과 비교 등에 필요한 부분만 선택한다. 승인 기능은 과제가 요구할 때 추가한다.

## 시각 패턴

 밝은 표면, 상단 요약 지표, 넓은 비교 차트, 보조 현황의 정보 순서를 참고한다. 

## 배치 예시

```text
화면 제목 | 기간·대상·비교 기준 선택
현재 조건과 핵심 결과 요약
주요 비교 차트                 | 필요한 보조 지표
비교표: 대상 / 기준별 값 / 차이 / 판단 상태
선택 항목의 근거·상세 자료
```

표가 판단의 중심이면 차트보다 위에 둔다. 검토형 업무에서는 비교 대상의 기준별 차이와 근거를 나란히 볼 수 있게 한다. 최적화 과제라면 조건 입력, 실행 상태, 결과와 제약 충족 여부를 이 흐름에 맞춰 배치한다.

## 차트와 표의 가시성

- 공간 배치 과제는 막대 차트보다 평면도 비교를 우선한다. 후보별 작은 도면을 나란히 놓고 미감시 구역은 빗금으로 표시한다.
- 비용과 성과를 맞바꾸는 비교는 가로축 비용·세로축 성과의 점 그래프에 예산선·목표선을 긋는다.

- 추이는 선, 범주별 비교는 막대처럼 질문에 맞는 표현을 선택한다. 장식용 차트는 넣지 않는다.
- 제목, 단위, 기간, 비교 기준을 표시하고 계열 이름을 알아볼 수 있게 한다.
- 선 모양과 직접 라벨로도 계열을 구분하고 정확한 수치는 표에서도 확인할 수 있게 한다.
- 마우스 올리기에만 의존하지 않는다. 필요한 값은 선택이나 표로도 확인한다.
- 표의 숫자는 오른쪽 정렬하고 단위·소수점 기준을 통일한다. 긴 이름은 상세 또는 펼치기로 읽을 수 있게 한다.
- 상승·하락을 곧바로 성공·실패 색으로 연결하지 않는다. 업무상 좋은 변화인지 확인한다.
- 누락 값과 실제 0, 추정·예측·실측을 구분한다.

## 주요 행동과 상태

조회 조건 변경, 비교 대상 선택, 상세 근거 확인을 기본 흐름으로 한다. 내보내기, 검토 제출, 승인은 요구가 있을 때 추가한다.

| 상태 | 표현 |
|---|---|
| 데이터 없음 | 입력 필요 여부와 조회 조건 확인 방법 안내 |
| 일부 자료 누락 | 누락 항목과 비교 가능한 범위 표시 |
| 계산·조회 중 | 진행 상태 표시. 진행률을 모르면 임의의 백분율을 만들지 않음 |
| 실행 실패 | 실패 이유와 입력 수정 또는 재시도 방법 안내 |
| 조건 충족 결과 없음 | 위반한 조건과 수정할 입력을 연결해 표시 |
| 시간 제한·근사 결과 | 실제 계산 상태와 보장 범위를 결과 근처에 표시 |

좁은 화면에서는 요약과 주요 비교를 먼저 보여준다. 넓은 표는 이름 열을 유지한 가로 스크롤 또는 항목별 상세로 읽을 수 있게 한다.

## 과제 확인 후 정할 것

비교 기준, 데이터 출처와 기준 시점, 지표 계산식, 평가 가중치, 계산 보장 범위, 검토·승인 권한. 시각적 정렬과 색상으로 근거 없는 순위나 추천을 만들지 않는다.
