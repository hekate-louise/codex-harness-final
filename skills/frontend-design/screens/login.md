# 로그인 화면 유형

공통 색과 시각 원칙은 [디자인 기준](../design-reference.md)을 따른다.

## 사용할 때

인증이 필요한 웹 서비스의 진입 화면. 역할 구분과 로그인 후 이동은 과제 요구를 따른다. 회원가입, 비밀번호 재설정, 역할 선택은 필요한 경우에만 추가한다.

## 시각 패턴

색상 배경, 은은한 패턴, 밝은 중앙 카드를 참고한다. 문구와 시각 요소는 과제에 맞게 정한다.

## 배치 예시

```text
주제 패턴이 있는 색상 배경
  밝은 중앙 카드
    로그인 영역             선택적 소개 영역
    서비스 이름             주제에 맞는 시각 요소
    아이디                  서비스 목적 한 줄
    비밀번호
    오류 안내 위치
    로그인 버튼
```

소개 영역은 선택 사항이며 폼만 있는 카드로 줄일 수 있다. 좁은 화면에서는 로그인 폼을 먼저 보여주고 소개 영역은 아래로 옮기거나 생략한다.

## 패턴 방향

- 과제 주제에 맞는 단순한 선이나 도형을 사용한다.
- 적절한 주제 패턴이 없으면 회로 배선, 칩 윤곽, 웨이퍼 격자를 연상시키는 추상 패턴을 사용한다.
- 배경과 가까운 명도 또는 낮은 불투명도로 표현해 폼보다 눈에 띄지 않게 한다.
- CSS 또는 SVG 패턴으로 충분하며 큰 삽화는 필수가 아니다.

## 행동과 상태

입력에는 보이는 라벨을 붙이고 키보드로 이동·제출할 수 있게 한다. 비밀번호 표시 기능은 필요하면 제공한다.

| 상태 | 표현 |
|---|---|
| 입력 누락 | 해당 입력 근처에 필요한 값 안내 |
| 인증 중 | 버튼에 진행 상태 표시, 중복 제출 방지 |
| 인증 실패 | 폼 안에 실패 안내와 다시 시도할 방법 표시 |
| 서버 연결 실패 | 인증 실패와 구별해 재시도 안내 |
| 로그인 성공 | 실제 권한에 맞는 첫 화면으로 이동 |

## 과제 확인 후 정할 것

인증 방식, 필요한 역할, 첫 이동 화면, 계정 안내 필요 여부, 소개 영역 사용 여부, 배경색의 정확한 값. 화면의 역할별 표시와 서버의 권한 검사는 각각 구현한다.
