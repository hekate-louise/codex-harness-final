# 운영·품질 화면 유형

## 적용 기준

공통 색과 시각 원칙은 [디자인 기준](../design-reference.md)을 따른다.

## 시각 패턴

다음 구성을 업무에 맞게 선택한다.

- 좁고 밝은 사이드바. 메뉴 행 높이와 항목 사이 간격을 작게 유지한다.
- 얇은 상단 바와 작은 화면 제목. 큰 제목·설명 구역으로 본문을 밀어내지 않는다.
- 상단에 캡슐형 대상 선택 탭과 작은 도구 버튼을 배치한다.
- 요약은 낮고 가로로 긴 상태 카드로 표현한다. 왼쪽에 상태 이름, 오른쪽에 숫자를 둔다.
- 본문은 비슷한 폭의 상세 카드 2열이다. 큰 도면 하나와 별도 알림 패널을 주 구성으로 삼지 않는다.
- 카드 안에 진행 막대, 작은 수치 행, 연한 배경의 정보 묶음을 반복한다.
- 카드 경계선은 옅게, 모서리는 적당히 둥글게, 카드 사이 간격은 좁게 유지한다.

## 배치 예시

```text
좁은 메뉴 | 얇은 상단 바: 화면 제목 / 현재 역할
          | 대상 선택 탭                   작은 도구 버튼
          | 전체 / 조건 충족 / 주의 / 조치 필요: 낮은 상태 요약
          | 대상 상세 카드 A              대상 상세 카드 B
          |   대상 이름·상태                대상 이름·상태
          |   성과 지표와 핵심 수치       성과 지표와 핵심 수치
          |   작은 배치 도면               작은 배치 도면
          |   자원·비용 / 필수 조건       자원·비용 / 필수 조건
          |   검토할 항목                  검토할 항목
```

## 최적화 과제에 적용할 때

대상별 계획을 카드 단위로 삼고 성과, 미충족량, 제약 충족, 자원 수, 비용을 가까이 배치한다. 계산 조건과 모델은 상세 정보에서 확인한다. 집계 대상과 상세에 표시한 대상의 범위를 밝힌다.
예: 카메라 배치라면 층별 감시율·미감시 면적·필수 구역 충족 여부를 함께 보여준다.

## 행동과 상태

실제 구현에서는 대상 탭·상태 필터·상세 열기를 통해 필요한 대상을 찾게 한다. 정적 시안의 버튼은 동작하지 않는다.

| 상태 | 표현 |
|---|---|
| 정상 | 작은 상태 점과 조건 충족 문구 |
| 주의 | 주의 라벨과 목표 미달 수치 |
| 조치 필요 | 오류 라벨과 미충족 구역 이름 |
| 데이터 없음 | 카드 영역에 입력 또는 등록 안내 |
| 조회 중 | 같은 영역에 진행 상태 표시 |
| 조회 실패·갱신 중단 | 실패한 영역과 마지막 성공 시점 표시 |
| 권한 없음 | 허용되지 않는 조회·조치 안내 |

좁은 화면에서는 메뉴와 탭을 가로로 정리하고 카드 2열을 1열로 바꾼다. 카드 내부 수치 묶음은 가능한 범위에서 나란히 유지하되 읽기 어려우면 한 열로 바꾼다.

## 과제 확인 후 정할 것

대상 단위, 상태 판단 기준, 성과 계산 방식, 모델의 반영 범위, 갱신 방식, 역할별 권한, 필수 조건의 충족 정의. 지금의 도면과 수치는 실제 계산 결과가 아니다.
