# 교육·추천 화면 유형

공통 색과 시각 원칙은 [디자인 기준](../design-reference.md)을 따른다.

## 사용할 때

콘텐츠나 과정을 탐색하고 추천 이유를 확인한 뒤 다음 행동을 선택하는 웹 서비스. 교육뿐 아니라 식단 등 추천 과제에도 항목을 바꿔 적용할 수 있다. 학습 진도와 평가는 교육 과제에서 요구할 때 사용한다.

## 시각 패턴

 검색, 주제 분류, 제목이 있는 추천 묶음, 이미지 카드의 정보 구조를 참고한다. 웹 화면에 맞게 카드 열 수와 탐색 방법을 정한다.

## 웹 배치 예시

```text
서비스 메뉴 | 검색과 주제·조건 필터
           | 이어서 할 작업 또는 주요 추천
           | 추천 묶음 제목                 전체 보기
           | 카드          카드          카드
           | 다른 추천 묶음 또는 전체 목록

상세 화면: 제목 / 핵심 정보 / 추천 이유 / 내용 / 주요 행동
```

넓은 화면에서는 여러 열의 카드로 전체를 살필 수 있게 한다. 폭이 줄면 열 수를 줄인다. 가로 넘김은 선택 사항이며 숨겨진 카드를 스와이프로만 찾게 하지 않는다.

## 카드와 상세 정보

- 제목, 선택에 필요한 핵심 정보, 짧은 추천 이유를 우선 표시한다.
- 교육이면 수준·예상 학습 시간, 식단이면 제공일·식사 구분처럼 실제 업무의 판단 기준을 쓴다.
- 이미지는 유용할 때만 쓴다. 자료가 없으면 단순한 주제 아이콘이나 텍스트 중심 카드로 구성한다.
- 이미지 안의 글자에만 의존하지 않는다. 긴 제목도 확인할 수 있게 한다.
- 추천 묶음 개수는 고정하지 않는다. 같은 항목을 여러 묶음에 반복해 화면을 채우지 않는다.
- 상세에서는 추천 근거와 제한 조건을 확인하고 시작·선택 등 실제 행동으로 이어지게 한다.
- 개인화 입력이나 이력이 없으면 일반 추천이라고 표시한다. 인기·개인 맞춤이라는 근거 없는 표현은 쓰지 않는다.

## 주요 행동과 상태

검색·필터, 목록 탐색, 상세 확인, 시작 또는 선택을 기본 흐름으로 한다. 저장, 진도, 평가, 관리자 편집은 실제 요구에 따라 추가한다.

| 상태 | 표현 |
|---|---|
| 첫 방문·추천 정보 부족 | 일반 목록 또는 필요한 조건 입력 제공 |
| 검색 결과 없음 | 조건 완화와 초기화 제공 |
| 추천 생성 중 | 진행 상태를 추천 영역에 표시 |
| 이미지 없음 | 제목과 핵심 정보는 유지하고 대체 시각 요소 사용 |
| 추천 실패 | 실패 안내와 재시도 또는 일반 목록 제공 |
| 조건 충족 항목 없음 | 제약과 변경 가능한 조건 안내 |
| 이용 권한 없음 | 제한 이유와 가능한 다음 행동 안내 |

## 과제 확인 후 정할 것

추천 대상, 추천 기준과 설명, 입력 조건, 데이터 출처, 이미지 필요 여부, 상세에서 수행할 행동. 움직임보다 검색과 비교, 읽기 편한 웹 구성을 우선한다.
